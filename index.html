.DAT Packer

Build a new .art file out of 8-bit indexed .bmp frames — or drop .png frames and they'll be converted automatically (the first one quantizes its own colors down to a palette; any after that are colour-matched onto frame 0's palette). Every frame ends up sharing frame 0's 256-colour palette in the output. Colour index (0, 0, 255) — pure blue, or fully transparent pixels in a PNG — is read by the game as transparent. Use the ⬇ button on a frame to grab the resulting .bmp any time. This packer only builds simple multi-frame .art files (one static image per frame); it doesn't support the directional-animation layout some creature art uses. Some header fields aren't fully understood, so if a packed file shows up blank or transparent in-game, picking a known-working .art file below as a reference will copy its header and per-frame reserved bytes into the output instead of guessing.
