1. Einführung
---------------

Herzlich Willkommen. Wir bedanken uns nochmals für den Kauf von ARCANUM: Von Dampfmaschinen und Magie. Wir bei Troika haben in den vergangenen drei Jahren hart daran gearbeitet, ein echtes CRPG zu entwickeln, in dem Sie als Endbenutzer einen einzigartigen Charakter erstellen und entwickeln, nach Lust und Laune an Rollenspielen teilnehmen und in der Welt von ARCANUM nach Ihren Wünschen einzigartige Erfahrungen machen können. Wir haben uns zum Ziel gesetzt, Ihnen so viel Freiheit wie möglich zu bieten und gleichzeitig eine komplexe Geschichte und eine Vielzahl von Ereignissen mit einzuarbeiten, um Ihren Spielspaß zu erhöhen.

ARCANUM wurde so entwickelt, dass Sie mit den verschiedensten Charakteren spielen können. Zu deren Facetten gehören z.B. diplomatische, diebische, technologische, magische und kämpferische Charaktereigenschaften. Ungeachtet der von Ihnen gewählten Rasse oder des Geschlechts stehen Ihnen sämtliche Spielarten zur Verfügung. Als Elf wären Sie beispielsweise eher magisch orientiert, hätten daher größere Schwierigkeiten im Umgang mit Technologie als ein Zwerg. Diese Option steht Ihnen jedoch trotzdem offen, wenn Sie die Herausforderungen dieses Charaktertyps gern annehmen möchten.

Nachfolgend finden Sie eine kleine Auswahl der Charaktertypen, die Sie beim Spielen von ARCANUM ausprobieren können:

- magisch oder technologisch ausgerichteter Dieb
- einfacher Dieb ohne magische oder technologische Fähigkeiten
- Meuchelmörder
- Meuchelmörder/Dieb als Anfänger oder Gentleman
- Anfänger oder Gentleman ohne gewalttätige Ambitionen
- charismatischer Glücksritter mit Bauernschläue
- extrem gut oder extrem böse (Magier oder Technologe)
- Krieger ohne magische oder technologische Fertigkeiten
- ausgewogener Charakter, der sich sowohl der Magie als auch der Technologie bedient
- Revolverkämpfer
- Erfinder
- ein sehr einfältiger Charakter
- ein sehr hässlicher Charakter
- ein sehr überzeugender Charakter
- ein Charakter mit sehr viel oder ganz ohne Charisma

Sie werden feststellen, dass die Umgebung auf diese unterschiedlichen Charaktertypen auch unterschiedlich reagiert, und dass ihnen während des Spiels unterschiedliche Wege und unterschiedliche Quests offen stehen.

Während des Spiels gelangen Sie immer wieder in besonders schwierige Kampfsituationen, in denen Sie möglicherweise in den rundenbasierten Modus umschalten möchten.

2. So starten Sie ARCANUM
-----------------------

Installieren Sie das Spiel. 

Die AutoPlay-Funktion Ihres CD-ROM-Laufwerks startet das Setup-Programm. Starten Sie das Spiel nach der Installation über das Startmenü. Falls dies aus irgendeinem Grund nicht funktionieren sollte, können Sie das Programm "Setup.exe" mit Hilfe des Windows-Explorer auch direkt von der CD-ROM aus starten. 

Starten Sie das Spiel durch Anklicken von "Start / Programme / Sierra / Arcanum/ Arcanum" im Startmenü.

Durch die Anwahl von "Start / Programme / Sierra / Arcanum / Arcanum (abgesicherter Modus)" im Startmenü starten Sie das Spiel im Software-Rendering-Modus. 


3. So spielen Sie ARCANUM
-----------------------

Erstellen Sie einen Charakter, und starten Sie das Spiel.

5. DirectX
-----------


Falls Sie versuchen, das Spiel zu starten, ohne vorher DirectX 7.0a installiert zu haben, erhalten Sie folgende Fehlermeldung: 

"Die Datei Arcanum.exe ist mit der fehlenden Exportdatei DDRAW.DLL:DirectDrawCreateEx. verbunden."


Falls Sie diese Meldung erhalten, müssen Sie Ihre Version von DirectX auf Version 7.0a oder neuer aktualisieren. 

Sie haben zwei Möglichkeiten. Sie können DirectX 8.0a oder DirectX 7.0a installieren.


5.1) Installation von DirectX 8.0a

Der Einfachheit halber ist DirectX 8.0a auf der ARCANUM-CD bereits enthalten. Dies ist zum Zeitpunkt der Veröffentlichung von ARCANUM die aktuellste verfügbare DirectX-Version von Microsoft. 

DirectX 8.0a kann während des Setup-Vorganges über das AutoPlay-Programm oder nach dem Setup direkt von der CD installiert werden. 

Wenn Sie DirectX 8.0a über das Setup-Programm installieren, wählen Sie bitte bei entsprechender Aufforderung nicht die Option "JETZT NEU STARTEN" an. Um beste Leistung zu erhalten, starten Sie den Computer bitte nach Abschluss des Setup-Vorganges selbst neu, und kehren Sie ins AutoPlay-Menü von ARCANUM zurück. 

Installieren Sie DirectX 8.0a direkt von der CD (falls Sie dies während der Installation des Spiels nicht bereits getan haben). ARCANUM wird mit DirectX 8.0a ausgeliefert und fordert Sie während des Installationsvorganges des Treibers dazu auf. Falls Sie DirectX 8.0a selbst installieren möchten, sorgen Sie bitte dafür, dass sich die CD mit der Bezeichnung "ARCANUM: CD 1 Installations-CD" im CD-ROM-Laufwerk befindet. Wechseln Sie anschließend bitte in folgendes Verzeichnis auf der CD-ROM: 

	"\Directx"

	und doppelklicken Sie auf die Datei DXSETUP.EXE.


HINWEIS FÜR BENUTZER VON WINDOWS 95!!!

DirectX 8.0a benötigt für die Installation die DCOM-Utilities. Bei einigen Versionen von Windows 95 ist DCOM standardmäßig nicht enthalten. Falls Sie bei der Installation von DirectX 8.0a auf Ihrem Windows 95-Computer Probleme haben, könnte dies die Ursache dafür sein. 

Wenn Sie das Setup-Programm von ARCANUM auffordert, DirectX 8.0a zu installieren, und Sie Windows 95 benutzen, erhalten Sie gleichzeitig die Aufforderung, Version 1.3 von DCOM vor der Installation von DirectX 8.0a zu installieren. Starten Sie den Computer nach der Installation von DCOM anschließend NICHT neu, da anderenfalls die Installation von DirectX 8.0a übergangen wird. In diesem Fall können Sie DirectX 8.0a aber auch manuell installieren (siehe oben).

Falls Ihr Computer DCOM nicht automatisch über das Setup-Programm installiert hat, können Sie dies manuell nachholen. Stellen Sie sicher, dass sich die CD "ARCANUM: CD 1 Installations-CD" im CD-ROM-Laufwerk befindet. Wechseln Sie anschließend bitte in folgendes Verzeichnis auf der CD-ROM: 

	"\DCOM"

	und doppelklicken Sie auf die Datei DCOM95.EXE.


5.2) Installation von DirectX 7.0a

ARCANUM benötigt DirectX 7.0a. Falls DirectX 7.0a nicht auf Ihrem Computer installiert ist und Sie DirectX 8.0a nicht installieren möchten, richten Sie bitte folgende Verknüpfung auf Ihrem Desktop ein. Sie gelangen darüber zur Download-Site von Microsoft, von der Sie DirectX 7.0a herunterladen und installieren können. Sie müssen DirectX 7.0a installiert haben, um ARCANUM spielen zu können.

http://www.microsoft.com/downloads/release.asp?ReleaseID=16819



6. Hardware-Kompatibilitäts-Probleme
--------------------------------

Wir empfehlen, ARCANUM nur zusammen mit DirectX-kompatiblen Sound- und Grafikkarten zu benutzen. Obwohl wenn eine gewisse Möglichkeit besteht, dass ARCANUM mit Hardware funktioniert, die nicht kompatibel zu DirectX ist, könnte es zu folgenden Problemen kommen:

	1) Die Soundqualität ist schlechter.
	2) Das Spiel läuft langsamer.
	3) Das Spiel läuft überhaupt nicht.

Sollte Ihre Sound- oder Grafikkarte DirectX nicht unterstützen, wenden Sie sich bitte an Ihren Händler.

ARCANUM wird versuchen, Ihre Grafikkarte zu erkennen und die dazu passenden Einstellungen zu wählen. Falls ein 3D-Beschleuniger als primäre Grafikkarte vorhanden ist, wird ARCANUM versuchen, diese zu benutzen. Sollten Probleme auftreten, überprüfen Sie bitte, ob Sie die neuesten Treiber von der Website des Herstellers Ihrer Hardware verwenden.

Falls das Spiel startet, sobald die Charaktererstellung abgeschlossen ist, und die Menüleisten oben und unten am Bildschirm zu sehen sind, der Haupt-Spielbildschirm jedoch schwarz oder verzerrt erscheint, könnte dies durch ein Problem mit der 3D-Grafikkarte verursacht worden sein.

Falls Sie Probleme mit der Grafikkarte haben, können Sie die 3D-Beschleunigung ausschalten, indem Sie das Spiel verlassen und ARCANUM im Software-Rendering-Modus starten. Der Software-Rendering-Modus (abgesicherter Modus) steht über das Startmenü zur Verfügung.

Die Option des Software-Rendering-Modus' für die Befehlszeile "arcanum.exe" lautet "-no3d". 

Die Benutzung der Detonator3-Treiber von nVidia könnte Probleme verursachen. ARCANUM wird ordnungsgemäß funktionieren, wenn Sie die Detonator2-Treiber verwenden.
